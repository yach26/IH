# Crop Calendars — Maharashtra Pilot Crops (ICAR, 2022)

## Overview

This document defines growth stage timelines and critical nutrient windows for the four pilot crops grown in Kolhapur and Jalgaon, Maharashtra.
Nutrient application must be aligned with growth stage as described — application at wrong stages reduces efficiency and increases runoff risk.

---

## Rice — Growth Calendar (Kharif, Maharashtra)

**crop**: rice
**region**: kolhapur
**region**: maharashtra
**document_type**: crop_calendar

| Stage | Days After Transplanting (DAT) | Key Activity |
|-------|-------------------------------|--------------|
| Transplanting (basal) | 0 | Full P, 50% N, 50% K |
| Tillering | 21-28 | 25% N top-dress (critical window) |
| Panicle initiation | 45-55 | 25% N top-dress (final split) |
| Heading | 65-75 | No fertilizer — grain filling |
| Maturity | 100-120 | Harvest |

Critical nutrient windows:
- Tillering is the MOST critical window for N — deficiency at tillering directly reduces tiller count and therefore yield.
- Missing the panicle initiation N dose reduces grain count per panicle.
- Applications after heading are wasteful and increase grain N (unfavourable for milling).

Rainfall interactions:
- Heavy rainfall during tillering (>30 mm/day) causes N leaching from flooded rice fields.
- Recommendation: Apply N split only when no heavy rain is forecast in the next 48 hours.
- If rain is imminent, defer to the next dry window within the tillering window (21-28 DAT).

## Sugarcane — Growth Calendar (Adsali, Kolhapur)

**crop**: sugarcane
**region**: kolhapur
**document_type**: crop_calendar

Adsali variety (18-month cycle) is predominant in Kolhapur.

| Stage | Months After Planting | Key Activity |
|-------|----------------------|--------------|
| Germination | 0-2 | Basal P + partial N and K |
| Tillering | 2-4 | First split N |
| Grand growth | 4-8 | Heavy N + K split |
| Maturation | 8-14 | Reduce N, cease K |
| Harvesting | 14-18 | No fertilizer |

Grand growth phase notes:
- Sugarcane cane elongation requires the highest K supply.
- Potassium deficiency during grand growth manifests as premature yellowing of lower leaves.
- Drip fertigated K2O (via SOP or MOP solution) is preferred in drip-equipped fields.

## Cotton — Growth Calendar (Kharif, Jalgaon)

**crop**: cotton
**region**: jalgaon
**document_type**: crop_calendar

| Stage | Days After Sowing (DAS) | Key Activity |
|-------|------------------------|--------------|
| Germination + establishment | 0-15 | Basal P, K, starter N |
| Squaring | 45-55 | Split N + K (critical for boll set) |
| Boll development | 75-90 | Final N split |
| Boll opening | 100-120 | No fertilizer |
| Harvest | 130-160 | - |

Boll set (squaring) stage is the single most yield-critical fertilizer window.
Deficiency of N or K at squaring directly reduces boll retention.
Excess N at boll opening causes excessive vegetative growth (rank growth) and delays boll opening.

## Banana — Growth Calendar (Jalgaon, Tissue Culture)

**crop**: banana
**region**: jalgaon
**document_type**: crop_calendar

Tissue culture banana: 12-month crop cycle.

| Stage | Months After Planting | Key Activity |
|-------|----------------------|--------------|
| Rhizome establishment | 0-2 | Basal P + starter N and K |
| Vegetative growth | 2-4 | Split N + K |
| Bunch development initiation | 4-6 | Split N + K (critical for bunch size) |
| Shooting | 6-8 | Reduced N, continue K |
| Bunch filling | 8-10 | K only (K2O supports fruit filling) |
| Harvest | 10-12 | No fertilizer |

Banana is a potassium-hungry crop. K deficiency during bunch development causes premature ripening and smaller bunch weight.
Apply K2O through drip fertigation where available — weekly splits preferred over monthly bulk application.

## Agronomic Interaction Notes

- **Rice + heavy rain**: Delay N application. Never apply Urea into standing water during rain events.
- **Cotton + heat**: Avoid Urea application at air temperature > 38 degrees C — volatilisation losses can exceed 30%.
- **Banana + chloride**: MOP (KCl) is generally tolerated by banana in Jalgaon's alluvial soils, but excess Cl can suppress bunch weight. Monitor with leaf tissue analysis.
- **Sugarcane + waterlogging**: Waterlogged conditions cause N loss via denitrification — reschedule N if fields are waterlogged for >3 days.
